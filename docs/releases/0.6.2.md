- Search is now a real text field: move the cursor, select, paste, undo and type accents. Start typing, or press ⌘F.
- ⌘⌫ no longer stops a server while you're typing: it clears the text, as it does anywhere else. Move into the list with ↑ or ↓ first to stop one.

Headwaiter is in beta. If it gets a server wrong, right-click the menu bar icon, choose Capture Diagnostics and [open an issue](https://github.com/individual11/headwaiter/issues). Check the capture for private details first.

Needs macOS 15 or later, on Apple silicon or Intel.
