- Notifications when a server starts, or stops without you stopping it. Turn them on in Settings. Both are off by default.
- Notifications wait 10 seconds, so restarts and short test runs stay quiet. Click a start notification to open the server.
- Settings now has three tabs: General, Notifications and Projects.

Headwaiter is in beta. If it gets a server wrong, right-click the menu bar icon, choose Capture Diagnostics and [open an issue](https://github.com/individual11/headwaiter/issues). Check the capture for private details first.

Needs macOS 15 or later, on Apple silicon or Intel.
