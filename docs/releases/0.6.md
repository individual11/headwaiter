- Use the list from the keyboard. Type to filter by name, project, framework or port, move with ↑ and ↓, and press Return to open. ⌘C copies the URL and ⌘⌫ stops the server.
- Reveal a server's or project's folder in Finder (⌘R), or open it in your terminal (⌘T). Both are in the right-click menus too. Choose the terminal in Settings.
- An optional log keeps one line for each start and stop, with how long the server ran. Turn it on in Settings, and view, filter or clear it any time. It's off by default and stays on your Mac.

Headwaiter is in beta. If it gets a server wrong, right-click the menu bar icon, choose Capture Diagnostics and [open an issue](https://github.com/individual11/headwaiter/issues). Check the capture for private details first.

Needs macOS 15 or later, on Apple silicon or Intel.
