First public download. This is a beta.

- Shows the dev servers running on your Mac, grouped by project, with open, copy, stop and force quit.
- Detects Node, Python, Go and Ruby servers, and Docker containers with published ports.
- Updates itself. Headwaiter asks before it checks automatically.

Docker, Go and some Python setups have mostly been tested with hand-written cases. If Headwaiter gets a server wrong, right-click the menu bar icon, choose Capture Diagnostics and [open an issue](https://github.com/individual11/headwaiter/issues). Check the capture for private details first.

Needs macOS 15 or later, on Apple silicon or Intel.
